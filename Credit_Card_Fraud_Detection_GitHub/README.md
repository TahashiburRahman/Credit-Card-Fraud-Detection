# Credit Card Fraud Detection

Machine learning project for detecting credit card fraud using the ULB dataset.

## Files
- deployment/fraud_model.pkl : Trained model
- deployment/scaler.pkl : Scaler
- deployment/feature_columns.pkl : Feature order
- deployment/predict.py : Prediction script
- requirements.txt : Required libraries

## How to Use

Install libraries:
pip install -r requirements.txt

Run example:
python deployment/predict.py
